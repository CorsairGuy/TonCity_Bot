# Проверки регрессий общей карты

После установки зависимостей фронта (`npm ci --prefix src/web/client`):

```sh
node scripts/tests/city-world-regressions.cjs
node scripts/tests/city-sections.cjs
npm run build --prefix src/web/client
```

Проверки исполняют реальные обработчики исходников с управляемыми состоянием, API и БД. Они не подключаются к игре и не используют токены. Проверяются отмена отложенного выбора, частичное сохранение и повтор ускорителей, смена состава прогноза, публикация и сохранение секций, устаревшие ответы и ошибки обновления.

Это целевые проверки алгоритмов, а не полная браузерная проверка страницы. Жесты дополнительно проверялись в Chromium на настоящем Canvas с тестовыми городами: pinch с разным порядком отпускания пальцев, touchcancel, обычный тап, совместимые mouse-события, прерывание наезда и смена обработчиков во время жеста. Боевые аккаунты и расход ресурсов не использовались.
