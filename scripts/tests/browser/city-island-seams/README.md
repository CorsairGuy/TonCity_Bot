# Проверка стыков подложек в Chromium

Стенд использует настоящие `cityIsland` и `mapSprites`, без React, БД, игровых аккаунтов и API.
Синтетический тест воспроизводит старую ошибку фильтрации обрезанных краёв на дробной границе и проверяет новое покрытие без щелей/двойной альфы: 72 сочетания масштаба, DPR, альфы и дневного/ночного цвета в диапазоне фильтрации выбранного mip (не более 2:1).
Также рисует обе настоящие подложки на пяти масштабах и DPR 1/2/3, проверяет две общие загрузки атласов и отсутствие ошибок/внешних запросов.

После установки зависимостей фронтенда:

```sh
node scripts/tests/browser/city-island-seams/server.mjs
# В другом терминале:
PLAYWRIGHT_MODULE=/path/to/playwright-core CHROMIUM_PATH=/usr/bin/chromium node scripts/tests/browser/city-island-seams/run.cjs
```

Можно использовать установленный `playwright` без переменных. `PORT` меняет порт сервера, `ISLAND_FIXTURE_URL` — адрес теста; `ISLAND_SCREENSHOTS` сохраняет PNG увеличенных подложек. Проверки не утверждают побайтовое совпадение с игровым GPU-рендером: они проверяют отсутствие добавленного нами шва.
