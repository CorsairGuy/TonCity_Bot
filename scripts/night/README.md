# Ночная разметка зданий города

Смена суток на карте города (`src/web/client/src/components/mapNight.ts`) берёт готовые ночные слои из
`src/web/sprites/night/`. Их собирает `export.py` по ручной разметке каждого здания в `ov/*.json`: где
настоящие окна (ночью светятся только они), какие окна образуют квартиру (свет включается и гаснет
квартирами) и что светится снаружи (вывески, прожекторы, фонари у входа). Фонари на дорогах
расставляются сами по тротуарам дорожных тайлов.

Нужны Python 3 и `numpy`, `scipy`, `pillow`. Спрайты берутся из `src/web/sprites` (то, что качает
`scripts/download-sprites.js`).

```bash
python3 scripts/night/export.py     # пересобрать src/web/sprites/night/ (≈20 с)
```

## Когда пересобирать

- После `download-sprites.js`, если игра перерисовала здания: разметка в долях кадра, но окна могли сдвинуться.
- После правки `ov/*.json`.

Новое здание без разметки ночью просто тонируется вместе с картой, без света в окнах. Чтобы оно
светилось, добавьте ему запись в `ov/` (любой файл, ключ — имя спрайта) и пересоберите.

## Инструменты разметки

Все координаты — доли кадра (x — от ширины, y — от высоты), 0..1. Кадр уменьшается до ширины 384 px,
пиксельные пороги ниже — в этих пикселях.

- `python3 scripts/night/gen.py preview OUT.png NAME [NAME …]` — строка на здание: день с сеткой 0.1,
  найденные окна (цвет — квартира), ночное превью.
- `python3 scripts/night/gen.py zoom NAME OUT.png x0 y0 x1 y1` — кусок кадра ×3 с сеткой 0.02.
- `python3 scripts/night/gen.py pick NAME x y [x y …]` — средний цвет 3×3 в точке (для цвета стекла).

## Схема записи (`ov/*.json`, объект по имени спрайта)

Окна:
- `colors: [[r,g,b,допуск], …]` — стекло по цвету (самый точный способ, цвет брать через `pick`).
  Без `colors` — автопоиск: пиксели темнее соседей (`dk`, по умолчанию 10, радиус `r` 7) или голубое
  стекло, плюс повторяемость (`rep`, по умолчанию 4 похожих окна). Часто цепляет рамы — проверять.
- `inc` / `incp` — прямоугольники / многоугольники, где искать окна (фасады в изометрии — параллелограммы).
- `ex` / `exp` — где не искать (вывески, крыши, фонтаны, деревья, бассейны, купола).
- `amin` (мин. пикселей в окне, 5), `amax` (больше — «стеклянная стена», 500), `fill` (заполнение рамки, 0.35),
  `open: true` — разрезать тонкие перемычки.
- Стеклянные стены: `split: [w,h]` — резать на панели, `skew` (например 0.577) — по линиям этажей, `bigfill`.
- `unit` — на каком расстоянии окна объединяются в квартиру (3 px; держать квартиры по 1–3 окна).
- `warm` — % тёплого света (70; офисам ~45 — больше белого и холодного).
- `none: true` — окон нет (парки).
- `same: "BASE.png"` — звёздная версия берёт правила базового здания, свои ключи дописываются рядом.

Подсветка (`lights: […]`, ночью горит всегда):
- `{"t":"emit","r":[x0,y0,x1,y1],"rgb":[r,g,b,доп]?,"minsat":0.3?,"own":true,"k":1.25,"blur":3,"halo":0.8,"c":[r,g,b]?}` —
  светятся пиксели прямоугольника (по цвету, если задан): вывески, неон, витрины.
- `{"t":"spot","x":…,"y":…,"rad":0.08,"sq":0.58,"c":[255,190,110],"g":0.6}` — пятно света на земле у входа.
- `{"t":"up","p":[x1,y1,x2,y2],"h":0.25,"n":0,"c":[…],"g":0.6}` — заливка фасада снизу вверх от линии основания,
  `n` — число отдельных прожекторов.
- `{"t":"bulb","x":…,"y":…,"rad":0.018,"c":[…]}` — маленькая яркая лампа (на крыше высотки — `[255,60,50]`).

Правило: светятся только настоящие стёкла, лучше пропустить пару окон, чем зажечь стену; подсветки
1–4 штуки на здание, правдоподобные для него.
