# TON City Bot

Бот для игры [TON City](https://game.toncity.io) (веб-приложение Telegram про строительство города) и веб-панель для управления им.

Бот ведёт сразу много игровых аккаунтов: каждый день заходит в игру, крутит колесо фортуны, решает мини-игры, собирает прибыль, улучшает город и столицу гильдии, выполняет квесты, следит за рынком. Всё это видно и настраивается в браузере через панель.

> Проект неофициальный и с разработчиками игры не связан. Используйте на свой страх и риск.

---

## Что умеет

**Каждый день, сам:**
- ежедневный вход, колесо фортуны, путь мэра, дорога верности, реклама за награды;
- мини-игры: вордли, 2048, сапёр, судоку, викторина (бот запоминает правильные ответы);
- сбор прибыли города и ресурсов столицы гильдии, стейкинг в Федрезерве;
- промокоды из списка в настройках.

**Город и гильдия:**
- прокачка города по заранее рассчитанным раскладкам: строит, двигает и улучшает здания, открывает новые участки;
- улучшение столицы гильдии и гильдейские квесты;
- редактор карты города и столицы прямо в панели.

**Рынок:**
- статистика цен и сделок, автоскупка по заданным ценам, выставление лотов;
- уведомления о ценах в Telegram.

**Удобства:**
- если в игре идут техработы, бот сам встаёт на паузу и пишет об этом в Telegram, а потом продолжает;
- панель можно установить на телефон как приложение (PWA);
- вход в панель по паролю.

## Как запустить

Понадобится **Docker** с Docker Compose. Готовый образ бота (код, зависимости и собранная панель) собирается в GitHub Actions на каждое изменение в `main` и лежит в `ghcr.io/corsairguy/toncity_bot`, на сервере ничего собирать не нужно.

```bash
# 1. Скачать проект (нужны docker-compose.yml, .env.example и папка config/)
git clone https://github.com/CorsairGuy/TonCity_Bot.git
cd TonCity_Bot

# 2. Создать файл настроек: пароль базы и ключ обновлятеля WATCHTOWER_TOKEN
cp .env.example .env
#    WATCHTOWER_TOKEN — любая длинная случайная строка, например: openssl rand -hex 32

# 3. Запустить базу, бота и обновлятель
docker compose up -d
```

Панель откроется на `http://localhost:3000`. Дальше:

1. На странице **Аккаунты** добавьте игровые аккаунты.
2. На странице **Настройки** задайте пароль панели и включите нужные функции. Там же указываются токен Telegram-бота и чат для уведомлений.

Если панель открыта не только на своём компьютере, пароль обязателен.

### Обновление

Внизу меню панели видна версия бота. Когда на GitHub появляется новая версия и её образ собран, там же появляется кнопка **«Обновить»**: бот скачивает новый образ через Watchtower и перезапускается (обычно меньше минуты). `.env`, `config/`, база и логи при этом не меняются.

- **Автоматически:** `WATCHTOWER_AUTO=true` в `.env` — обновления ставятся сами по расписанию `WATCHTOWER_SCHEDULE` (по умолчанию 21:00 UTC = 02:00 GMT+5). Применить: `docker compose up -d`.
- **Вручную из консоли:** `docker compose pull bot && docker compose up -d bot`.
- **Откат:** в `.env` указать `BOT_TAG=sha-<полный коммит>` (теги видны в GitHub → Packages), затем `docker compose up -d`. Вернуться на свежую версию — очистить `BOT_TAG`.

### Разработка с правкой кода на месте

Код с хоста подключается в контейнер, бот перезапускается сам при правках кода в `src/` (встроенный в Node режим `--watch`):

```bash
cd src/web/client && npm install && npm run build && cd ../../..
docker compose -f docker-compose.yml -f docker-compose.dev.yml up -d --build db bot
```

### Без Docker

Нужна своя MariaDB, адрес которой указан в `.env`.

```bash
npm install
npm start        # обычный запуск
npm run dev      # с перезапуском при изменении кода
```

### Несколько копий на одном сервере

Каждой копии нужна своя папка и свой `.env` с разными `STACK_NAME`, `WEB_PORT` и `DB_EXPOSED_PORT`.

## Где что лежит

```
src/index.js          запуск бота и всех фоновых циклов
src/modules/          игровые функции: фортуна, вордли, город, столица, рынок…
src/api/client.js     обращение к серверу игры
src/db/               таблицы базы данных
src/web/server.js     веб-сервер панели
src/web/routes/       API панели
src/web/client/       сама панель (React)
config/               справочники зданий, раскладки города, фазы прокачки
scripts/              служебные скрипты (проверка аккаунтов, снимок схемы БД)
```

Личные данные (`.env`, `config/settings.json`, база в `db_data/`, логи) в репозиторий не попадают.
