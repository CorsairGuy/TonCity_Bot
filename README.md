# 🏙️ TON City Bot

**Бот для игры [TON City](https://game.toncity.io) и веб-панель для управления им**

## Быстрый старт

Нужен **Docker** с Docker Compose. Готовый образ (код, зависимости и собранная панель) лежит в `ghcr.io/corsairguy/toncity_bot`, на сервере ничего собирать не нужно. Образы есть под `amd64`, `arm64` и `arm/v7`.

```bash
git clone https://github.com/CorsairGuy/TonCity_Bot.git
cd TonCity_Bot
cp .env.example .env        # поменяйте DB_PASSWORD
docker compose up -d        # база + бот + обновлятель
```

Панель откроется на **http://localhost:3000** (порт задаёт `WEB_PORT`).

## Первые шаги после запуска

1. **Настройки → Безопасность**: задайте пароль панели. Если панель доступна не только с этого компьютера, пароль обязателен.
2. **Аккаунты**: вставьте ссылку входа из игры вида `https://game.toncity.io/auth?t=...` и нажмите «Добавить». Бот сам получит токены, узнает имя аккаунта и запустит для него все циклы, перезапуск не нужен.
3. **Настройки → Telegram-уведомления**: токен бота от @BotFather и чаты для уведомлений (необязательно).
4. **Города → Общий план улучшений** или карта конкретного города: задайте, что прокачивать. Без целей бот город не трогает.

## Что бот делает сам

Бот и панель работают в одном процессе. После старта для каждого аккаунта проверяется сессия, затем запускаются фоновые циклы.

### Раз в сутки (по UTC)

Проход идёт по всем аккаунтам. Сделанное отмечается, поэтому после перезапуска бот не повторяет уже выполненное сегодня.

| Задача | Что происходит |
|---|---|
| Ежедневный вход | Забирает награду дня, сохраняет график наград на весь 28-дневный цикл. |
| Колесо фортуны | Бесплатное вращение, если у аккаунта есть Павильон удачи. |
| Склад | Синхронизирует предметы аккаунта. Наборы сам **не** открывает. |
| Политики | Синхронизирует политики и пополняет общую библиотеку описаний. |
| Башня Сатоши | Синхронизирует позиции и баланс. |
| Рынок | Выставляет предметы из списка `sellItems` в настройках (выключено по умолчанию). |
| Промокоды | Активирует коды из списка в настройках, ведёт историю. |
| Аудиториум и Технофабрика | Обновляют снимок спецзданий гильдии. |
| Гильдейские квесты | Каждый аккаунт проверяет и забирает свою награду за квесты. |
| Автовыполнение квестов | Реклама, стейкинг, сапёр, судоку, викторина — только если сейчас есть подходящий квест (см. [Квесты](#сфера-миссий-квесты)). |
| Дорога верности | Отдельный суточный цикл: забирает награду, когда серия дней дошла до порога. |
| Вордли | Отдельный цикл для аккаунтов с Оплотом Мудрости: аккаунты по очереди, по одному слову за раз. |

### Постоянно

| Цикл | Период | Что делает |
|---|---|---|
| Прокачка города | 6 ч или сразу после сохранения целей | Улучшает здания по вашим целям, открывает соседние секции за монеты. |
| Прокачка столицы | постоянно, только у лидера гильдии | Улучшает здания столицы по целям. |
| Квесты гильдии | постоянно, у лидера | Создаёт и забирает гильдейские квесты. |
| Сбор прибыли | 6 ч | Забирает прибыль города и обновляет баланс и показатели. |
| Сбор ресурсов столицы | 12 ч | Монеты и кристаллы столицы, только лидер гильдии. |
| Стейкинг | к ближайшему сроку | Забирает созревшие вклады Федрезерва. |
| Ускорители | когда освобождается слот | Держит активными ускорители из очереди на карте города. |
| Технофабрика | по окончании крафта | Забирает готовое и запускает следующую переработку из очереди. |
| Цены рынка | постоянно | Мониторинг цен и пост в Telegram (если настроен). |
| Сатоши TP/SL | постоянно | Следит за курсом на биржах и закрывает или открывает позиции по условиям. |
| Автообновление | 10 мин | Ставит новую версию, если включено (см. [Обновления](#обновления-и-каналы-версий)). |

> [!NOTE]
> Покупки, активация ускорителей и траты кристаллов бот делает только по вашей явной настройке или кнопке.

## Веб-панель: все разделы

Почти все страницы читают сохранённый снимок из базы и открываются мгновенно, без запросов к игре. Свежие данные — кнопкой **«Обновить»**. Названия разделов совпадают с меню.

### Аккаунты

- Добавление аккаунта ссылкой входа `https://game.toncity.io/auth?t=...` (если аккаунт уже есть, он обновится, а не задвоится).
- Таблица аккаунтов со статусом: **Активен**, **Токен протух**, **Подключается…**, **Нет токена**. Сортировка по статусу поднимает проблемные наверх.
- Удаление аккаунта: бот сразу перестаёт с ним работать.

### Хранилище

**Предметы** — склад всех аккаунтов: ящики, материалы, ускорители, осколки, сортировка по типу и редкости. Клик по предмету открывает окно аккаунта, где можно:
- **продать** предмет игре;
- **активировать** ускоритель;
- **объединить** ускорители по правилам игры;
- **открыть** наборы с показом выпавшего и выбрать **цель** гарантии набора.

Те же действия есть массово, сразу на всех аккаунтах: «Активировать на всех», «Объединить максимум на всех», «Установить цель на всех».

**Политики** — карточки политик каждого аккаунта по редкостям: применить или снять, повысить уровень (стаж и осколки), улучшить редкость, провести реформу (камень реформ), создать тайную политику из осколков, расформировать (для эпических и выше всегда с подтверждением). Политики открываются в игре с 1 000 000 населения.

### Задания, Федрезерв, Павильон удачи

- **Ежедневная награда** — карточки всего 28-дневного цикла наград по каждому аккаунту.
- **Ежедневная реклама** — статус просмотров и кнопка «Смотреть» с живым прогрессом. Просмотр идёт на сервере, поэтому переживает перезагрузку страницы.
- **Стейкинг** (Федеральный Резерв) — вклады в монетах и кристаллах: активные и собранные, сколько вложено и к получению, свободные слоты. «Вложить всем» одним окном, отмена монетного вклада с подтверждением. Созревшие вклады бот собирает сам.
- **Колесо Фортуны** — бесплатное и платное вращение по каждому аккаунту и «крутить всем». Показываются только аккаунты, у которых есть павильон.

### Оплот Мудрости (мини-игры)

| Игра | Как решает бот |
|---|---|
| **Вордли** | Каждый день сам угадывает слово по словарю `config/wordle-words.txt` (подбор по максимуму информации, в среднем ~3,8 попытки на весь парк). Тратит не больше 5 попыток, 6-я оставлена вам: окно «Подать на все» отправляет ваше слово на все аккаунты. Отгаданное слово уходит в Telegram. |
| **Сапёр** | Логический вывод по открытым клеткам, угадывает только когда верных ходов нет. |
| **Судоку** | Перебор с возвратом, решает всегда. |
| **Викторина** | Запоминает правильные ответы в базе и с каждым разом отвечает точнее. |
| **2048** | Автоигра в фоне прямо из таблицы или с просмотром доски в окне. Ход выбирает алгоритм [2048-ai](https://github.com/nneonneo/2048-ai) Роберта Сяо (nneonneo, лицензия MIT), собранный в WASM. |

Сапёр, судоку и викторина запускаются кнопкой, прогресс идёт в реальном времени и переживает перезагрузку страницы. Их же может запускать автовыполнение квестов.

### Профиль

- **Путь Мэра** — уровни и награды. Бот проверяет и забирает их, когда прибыль города дорастает до порога, без лишних запросов.
- **Достижения** — значки всех аккаунтов с уровнями, прогресс в подсказке.
- **Промокоды** — ввод кода на все аккаунты сразу и история активаций.

### Города и карта города

**Города** — сводка всех городов: монеты, кристаллы, прибыль в час (сейчас и после всех улучшений), население, счастье. Кнопка обновляет постройки всех городов прямо из игры.

**Общий план улучшений** — целевой уровень по зданию для всех городов сразу (подробнее — [Прокачка](#прокачка-города-и-столицы)).

**Карта города** открывается из таблицы. На ней видны все здания, а в боковой панели — вкладки:

| Вкладка | Что делает |
|---|---|
| Показатели | Прибыль, население, счастье, полиция, больницы, пожарные, парки — по формулам игры, с учётом бонуса гильдии, политик и разнообразия. Разбивка дохода как в игре. |
| Улучшение | Ручная очередь «улучшить следующими». |
| План | Целевой уровень для конкретной клетки. |
| Строительство | Построить здание на выбранной клетке. |
| Перемещение | Передвинуть здание, цели и очередь переезжают вместе с ним. |
| Снос | Снести здание. |
| Реконструкция | Перестройка здания за «Компонент» (можно запланировать на нужный уровень). |
| Реновация | Обновление здания за «Мастерплан». |
| Ускорители | Ручная активация и **очередь «всегда держать активным»** — бот включает следующий ускоритель, как только освободится слот. |
| Прогноз | Что и когда бот запустит в ближайшие 3 суток при текущем бюджете и строителях. |
| Лог | Последние действия по городу, и бота, и ручные, с реальной длительностью стройки. |

Карта обновляется сама при каждом изменении, без перезагрузки.

### Столицы и гильдии

- **Столицы** — монеты, кристаллы и прибыль столиц гильдий, где у бота есть аккаунт. Карта столицы устроена как карта города: Улучшение, План, Строительство, Перемещение, Снос, **Ускорить** (за кристаллы), Лог, Прогноз. Показывает уровень штаб-квартиры и силу экономики. Действия выполняются от аккаунта-лидера.
- **Общий план улучшений столицы** — то же, что для городов.
- **Гильдии** — гильдии, где аккаунт лидер: бафы гильдии, заявки на вступление (принять или отклонить), участники (повысить до офицера, понизить, исключить), настройки гильдии как в игре (тип, порог входа по населению и прибыли, членский взнос, порог неактивности). Предупреждает, если один игровой аккаунт задвоен в базе.
- **МИД** — альянсы (заявки, принятие, разрыв, повышение уровня), враги и тарифы, кампании гильдий (начать, вступить в бой, история).
- **Строители** — цены и покупки строителей по аккаунтам.
- **Аудиториум** — Вечный аудиториум: условия входа, баланс Почёта, уровни престижа и витрина обмена Почёта на предметы.
- **Фабрика** — Технофабрика: станки и тиры, запуск переработки и **очередь**, которую бот разбирает сам по мере освобождения станка; вложение в казну гильдии.

### Сфера миссий: квесты

- **Дорога верности** — уровни и пороги серии дней (3, 7, 14, 30…). Награды бот забирает сам.
- **Квесты** — гильдейские квесты каждого аккаунта с прогрессом, кнопки «Выполнить», «Забрать» и активация ускорителя под квест. Значок **«Автовыполнение»** включает фоновое выполнение по типам: реклама, стейкинг, сапёр, судоку, викторина. Действие выполняется, только если у аккаунта прямо сейчас есть подходящий незавершённый квест; награда забирается сразу.
- **Уровни квестов** — уровни гильдейских квестов и взнос Почёта с выбранных аккаунтов гильдии.

Если в `.env` задан `TONCITYQUESTS_BOT_HASH`, активные квесты гильдии дополнительно отправляются на toncityquests.ru.

### Мэрия

- **Распределение** — данные airdrop по аккаунтам (развитие города, активность, достижения, сеть друзей, транзакции).
- **Библиотека политик** — общий каталог описаний политик, собранный со всех аккаунтов: игра показывает только то, что открыл конкретный аккаунт.
- **Разнообразие** — бонус к доходу за разнообразие зданий (открывается с 1 000 000 населения).
- **Городской розыгрыш** — прогресс, прогноз готовности и сбор осколков.

### Магазин

**Ускорители**, **Наборы**, **Политики** (осколки и тайные политики): предложения магазина по всем аккаунтам. Видно, хватает ли монет или кристаллов, сколько осталось в дневном лимите. Количество за одно нажатие, «Купить всем» с учётом лимита и баланса каждого аккаунта.

### Центральный рынок

| Раздел | Что внутри |
|---|---|
| **Офферы** | Лоты рынка с фильтрами как в игре: категория, редкость, тип торгов (прямой, аукцион, предложения), валюта. Покупка с выбранного аккаунта. **Автопокупка**: правила «купить предмет до цены X» с бюджетом и набором аккаунтов, при желании и эскроу-лоты. **Снайп**: купить конкретный эскроу-лот ровно в момент открытия. |
| **Листинги** | Ваши лоты на всех аккаунтах. Выставить предмет, политику или осколок (прямая продажа, аукцион, предложения; срок 1/3/7 дней; анонимно) сразу на одном или всех аккаунтах. Снять один лот или все. |
| **Статистика** | Сколько кристаллов получено и потрачено на рынке по аккаунтам. |
| **Покупки / Продажи** | История сделок. |

Мониторинг цен публикует сводку в Telegram: при снижении цены приходит новое сообщение, остальное время старое тихо редактируется.

### Башня Сатоши

Трейдинг GRAM/USDT с плечом за кристаллы игры.

- График курса с реальных бирж (Binance, OKX, KuCoin) и курс игры, таймфреймы от 1 минуты до 1 дня.
- Открытие лонга и шорта на одном или нескольких аккаунтах; расчёт ликвидации, безубытка и комиссии.
- **Тейк-профит и стоп-лосс** в процентах ROI, процентах движения курса или конкретной ценой, с оценкой в кристаллах. В игре их нет, позиции закрывает бот по биржевому курсу.
- **«Ждать курс»** — условный ордер: позиция откроется, когда курс дойдёт до цены.
- Открытые и закрытые позиции, профит за 24 часа и 7 дней.

## Прокачка города и столицы

Бот прокачивает только то, что вы задали. Цели берутся из трёх источников, по приоритету:

1. **Ручная очередь** (вкладка «Улучшение») — конкретные клетки «улучшить следующими». Одна клетка может стоять в очереди несколько раз подряд, выполненная запись вычёркивается.
2. **Личный план** (вкладка «План») — целевой уровень для конкретной клетки.
3. **Общий план** (страница «Общий план улучшений») — целевой уровень по зданию для всех городов или столиц. Звёздные тиры здания («Городской банк» и «Городской банк ★2») настраиваются отдельно.

Как работает проход:

- **Город** ограничен свободными строителями (с учётом бонуса гильдии и политики кабинета) и тратит не больше **80% монет**. Короткие улучшения запускаются первыми.
- **Столица** прокачивается только от лидера гильдии; строителей у неё нет, ограничение — те же 80% монет.
- Сохранение целей в панели будит цикл сразу, ждать 6 часов не нужно.
- Соседние секции города открываются за монеты; секции за кристаллы бот не покупает.
- Реконструкция по плану ждёт нужного уровня и конца стройки и не занимает строителя.

## Техработы в игре

Когда игра уходит на обновление (ответ `503` с `maintenance`), бот ставит на паузу **все** запросы: и свои циклы, и действия из панели. Раз в 5 минут один пробный запрос проверяет, вернулась ли игра; после этого работа продолжается сама. В панели в это время виден баннер, в Telegram приходит уведомление.

## Обновления и каналы версий

Всё делается в панели: **Настройки → Обновления**.

| Канал | Что ставится |
|---|---|
| **Свежая сборка ветки** (`main`, `dev`…) | Каждый новый коммит ветки, как только собран образ. |
| **Стабильный** | Только релизы из GitHub Releases. |
| **Закрепить версию** | Конкретный релиз (`1.0`) или прошлая сборка. Сама не обновляется никогда. |

- **«Ставить обновления автоматически»**: для ветки и стабильного канала бот раз в 10 минут проверяет новое и ставит сам, но не посреди ручных операций. Выключено — только кнопкой «Обновить сейчас».
- Список релизов с описанием изменений, статус сборки нового образа на GitHub.
- **«Вернуться на …»** — откат на предыдущую запущенную версию.

Переключает версии сервис `updater`: скачивает образ нужного тега, прописывает `BOT_TAG` в `.env` и пересоздаёт только контейнер бота (обычно меньше минуты). `config/`, база и логи не меняются. В режиме разработки переключение недоступно.

<details>
<summary><b>Теги образа и выпуск релиза</b></summary>

Теги `ghcr.io/corsairguy/toncity_bot`:

| Тег | Откуда |
|---|---|
| `main` (он же `latest`), имя любой ветки | push в ветку |
| `1.0` | релиз `v1.0` |
| `stable` | последний релиз, если это не пре-релиз |
| `sha-<коммит>` | любая сборка |
| `updater` | сам обновлятель, из `main` |

**Выпустить релиз:** GitHub → Releases → Draft a new release, тег вида `v1.0` из `main`, описание изменений — то, что панель покажет в списке релизов.

**Вручную из консоли:** `BOT_TAG=` в `.env`, затем `docker compose pull bot && docker compose up -d bot`.

Необязательный `GITHUB_TOKEN` в `.env` (без каких-либо прав) снимает лимит GitHub в 60 запросов в час на проверку версий.

## Установка подробно

### Docker Compose

`docker-compose.yml` поднимает три контейнера:

| Сервис | Что это |
|---|---|
| `db` | MariaDB 10.11, данные в `./db_data`. |
| `bot` | Бот и панель, готовый образ из GHCR. С хоста подключены только `./config` и `./logs`. |
| `updater` | Обновлятель: меняет версию бота по запросу из панели. |

Справочники из `config/` лежат копией внутри образа и при каждом запуске раскладываются в `config/`: обновлённый в git справочник приезжает на сервер вместе с новой версией, а слова, дописанные в словарь вордли на сервере, сохраняются. Изменения в `docker-compose.yml` применяются через `docker compose down && docker compose up -d`.

### Portainer

Стек описан в `docker-compose.portainer.yml`. Portainer хранит файл стека у себя, поэтому все данные (`config/`, `logs/`, `db_data/`) лежат в одной папке на сервере, её абсолютный путь задаёт `DATA_DIR`, а переменные вводятся в Portainer вместо `.env`.

1. **Токен для обновлятеля.** Portainer → значок пользователя → **My account** → **Access tokens** → **Add access token**. Токен показывается один раз.
2. **Стек.** **Stacks → Add stack**, имя `toncity_bot`. Содержимое — один из вариантов:
   - **Web editor**: вставить `docker-compose.portainer.yml`;
   - **Repository**: URL `https://github.com/CorsairGuy/TonCity_Bot`, reference `refs/heads/main`, compose path `docker-compose.portainer.yml`.
3. **Переменные** (Environment variables):

   | Переменная | Значение |
   |---|---|
   | `DATA_DIR` | Абсолютный путь к папке с данными, например `/DOCKER/toncity_bot`. Обязательно. |
   | `DB_PASSWORD` | Пароль базы. Обязательно. |
   | `BOT_TAG` | Канал: `latest`, `stable`, `1.0` или `sha-…`. |
   | `PORTAINER_TOKEN` | Токен из шага 1, нужен для смены версии из панели. |
   | `PORTAINER_URL` | Только если Portainer не на этом сервере на стандартных портах (обновлятель сам пробует https :9443, http :9000, http :9443). |
   | `STACK_NAME`, `WEB_PORT`, `DB_EXPOSED_PORT`, `DB_NAME`, `GITHUB_TOKEN`, `TONCITYQUESTS_BOT_HASH` | По желанию, как в `.env`. |

4. **Deploy the stack.** Контейнеры `<STACK_NAME>_db`, `_bot` и `_updater` должны быть в статусе running, панель — на `http://<сервер>:3000`.

С токеном «Обновить сейчас» в панели меняет `BOT_TAG` стека и передеплоит его с новым образом. Без токена бот работает, а версию меняют вручную: Stacks → стек → Editor → `BOT_TAG` → **Update the stack** с включённым **Re-pull image and redeploy**. Ошибки обновлятеля видны в логах контейнера `_updater`.

### Несколько копий на одном сервере

У каждой копии своя папка и свой `.env` с разными `STACK_NAME`, `WEB_PORT` и `DB_EXPOSED_PORT`. Имена контейнеров — `<STACK_NAME>_db`, `_bot`, `_updater`.

### Разработка

Код с хоста подключается в контейнер, бот перезапускается при правках в `src/` (режим `node --watch`):

```bash
cd src/web/client && npm install && npm run build && cd ../../..
docker compose -f docker-compose.yml -f docker-compose.dev.yml up -d --build db bot
```

Панель с горячей перезагрузкой: `cd src/web/client && npm run dev` (Vite проксирует `/api` на `:3000`). После правок фронта — `npm run build`.

### Без Docker

Нужны Node.js 22 и своя MariaDB, адрес которой указан в `.env`.

```bash
npm install
cd src/web/client && npm install && npm run build && cd ../../..
npm start        # обычный запуск
npm run dev      # с перезапуском при изменении кода
```

> [!CAUTION]
> Не запускайте два экземпляра бота против одной базы. Игра меняет токен при каждом обновлении сессии, и второй процесс «сожжёт» аккаунты.

## Настройки

**`.env`** — только окружение (образец — `.env.example`):

| Переменная | Назначение |
|---|---|
| `WEB_PORT` | Порт панели, по умолчанию `3000`. |
| `WEB_BIND` | Адрес прослушивания, по умолчанию `127.0.0.1`. В Docker задаётся `0.0.0.0`. |
| `DB_HOST`, `DB_EXPOSED_PORT`, `DB_USER`, `DB_PASSWORD`, `DB_NAME` | Подключение к базе. |
| `STACK_NAME` | Префикс имён контейнеров. |
| `BOT_TAG` | Канал версий, меняется из панели. |
| `TONCITYQUESTS_BOT_HASH` | Ключ toncityquests.ru, пусто — отправка выключена. |
| `GITHUB_TOKEN` | Необязательно, для проверки обновлений. |

**`config/settings.json`** — всё остальное. Большую часть меняет панель (Telegram, пароль, автовыполнение квестов, автообновление, мониторинг цен). Без кнопок в панели, правкой файла:

| Ключ | Что задаёт |
|---|---|
| `features.*` | Включение функций: `dailyLogin`, `fortune`, `journey` (Путь Мэра), `inventory`, `policies`, `satoshi`, `upgrading` (прокачка города), `capital` (столица и квесты), `market` (выставление `sellItems`), `marketMonitoring`. |
| `sellItems` | Предметы для ежедневного выставления на рынок: `[{"name": "...", "price": 100, "qty": 1}]`. |
| `promoCodes` | Промокоды для ежедневной активации. |
| `logLevel` | Подробность логов (меняется и в панели). |

## Безопасность

- Панель по умолчанию слушает только `127.0.0.1`. Открывая её наружу, обязательно задайте пароль.
- Пароль один, без логина; хранится хэшем (scrypt), сессия — подписанная cookie на 30 дней.
- Личные данные не попадают в git: `.env`, `config/settings.json`, база `db_data/`, логи, токены аккаунтов.
