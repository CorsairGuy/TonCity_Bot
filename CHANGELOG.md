# Журнал изменений

Память проекта: что и зачем менялось. Claude дописывает запись **после каждой законченной работы**, новые записи сверху.

Формат записи:

```
## ГГГГ-ММ-ДД — коротко, что сделано
- что изменилось и зачем (файлы, модули)
- на что обратить внимание дальше (если есть)
```

Без секретов: токены, пароли, ключи и chat id сюда не пишутся.

## 2026-10-13 — Переезд на диск Z и исправления

- Страница «Ежедневная награда»: сетка из 28 дней по снимку `DailyRewardSnapshot` без лишних запросов (`last_login` — `VARCHAR(40)`).

## 2026-08-21 — Цены улучшений на событии и повторы запросов
- Каталог зданий не обновлялся ни разу: нужен путь `/buildings/` со слэшем. Из-за этого на событии (−75%) бот считал цены вчетверо выше и пропускал улучшения.
- Сбой `/progress/` больше не усыпляет цикл прокачки на 6 часов, повтор через минуту. Пропуски очереди пишутся в лог с причиной.
- Повторы централизованы в `api/client.js`: только GET и только при отсутствии ответа. Изменяющие запросы не повторяются.
- Каталог зданий обновляется кнопкой «Обновить», а не на каждом проходе.

## 2026-08-19 — Планы города построчно

- Сбор стейкинга: `GET /federal-reserve/staking` у игры зависал, добавлены таймаут 15 с и фолбэк на вклады из БД.
- Башня Сатоши: «Ордер по цене» заменён галкой «Ждать курс» в «Новой позиции»; запуск апгрейдов города пачкой вместо одного раз в несколько минут.
